# Bible Readmap

Build a personalized Bible reading plan, configure it in English or German, and print it on landscape A4 or download it as PDF or HTML. Plan generation runs in the browser.

```sh
npm ci
npm run dev
```

Run `npm run build` to generate the server-rendered site in `dist/`. Use `npm run preview` to serve that build locally. Vite extracts chapter word counts from the Bible JSON during development and builds.
